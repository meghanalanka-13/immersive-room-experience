# Immersive Co-Repairs Website

## Overview
Turn the existing Co-Repairs concept into an immersive website that opens inside a premium service-center room. The opening view will feel spatial and cinematic, with the brand story floating in the room and changing as visitors scroll. Supporting content will continue below in a clean, practical format inspired by the supplied website.

## What I’ll build
- A full-screen opening room based on the warm reception space in the reference.
- Subtle depth, camera movement, foreground framing, light shifts, and perspective motion to create a convincing 3D feeling without sacrificing speed or clarity.
- Centered floating story beats for the core promise, goal, mission, and vision, revealed through scrolling.
- A compact navigation bar with clear service-booking and partner actions.
- Supporting sections for the ecosystem, benefits, sustainability, process, and contact details.
- A service-booking form and partner enquiry form as polished front-end interactions; submissions will remain demonstrational because data storage is not enabled.
- Responsive layouts for desktop and mobile, reduced-motion support, and accessible text contrast.

## Visual direction
- Warm ivory, limestone, charcoal, soft botanical green, and a restrained amber accent.
- Architectural, calm, premium, and human rather than technology-dashboard styling.
- Clean sans-serif typography, minimal borders, and tightly controlled cards only where information repeats.

## Technical details
- Use the generated room artwork as the main scene, layered with CSS perspective and scroll-driven parallax for a lightweight 3D effect.
- Build the experience in the existing TanStack Start site and use semantic design tokens throughout.
- Add route metadata for the finished public page and verify the experience at desktop and mobile sizes.
